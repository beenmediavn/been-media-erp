CÁCH CHẠY:
1. Giải nén đúng thư mục BEEN_MEDIA_ERP_V7_GREEN_GOLD.
2. Mở PowerShell NGAY TRONG thư mục này.
3. npm install
4. npm run dev
5. Mở http://localhost:3000

Kiểm tra thanh menu trái: cuối menu phải thấy “V7 GREEN GOLD • #15302B”. Nếu không thấy, bạn đang chạy nhầm bản cũ.
