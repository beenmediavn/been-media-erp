V7.13 - PWA + màn hình đăng nhập
- Bỏ tài khoản/mật khẩu mặc định khỏi ô đăng nhập.
- Bỏ dòng công khai tài khoản mặc định khỏi màn hình.
- Tắt autocomplete ở form đăng nhập để hạn chế trình duyệt tự điền lại sau đăng xuất.
- Cập nhật service worker theo network-first cho điều hướng, tránh icon PWA mở bản cache cũ/treo loading.
- Cập nhật manifest + icon PWA.

Lưu ý: trình quản lý mật khẩu của Chrome/Samsung/Google có thể vẫn đề nghị lưu mật khẩu ở cấp hệ điều hành. Nếu người dùng đã lưu trước đây, cần xóa mục đã lưu trong Password Manager trên điện thoại.
